* **Автосканирование репозитория:** автоматически находит файлы прошивок и утилит в корне и подпапках (`img`, `zip`, `tar`, `md5`, `bin`, `lz4`, `xz`, `gz`, `apk`, `sh`, `bat`, `payload`).
